# Non-goals (product)

These records are **rejected growth** for `zero-employee` core. They are not
intake `NOT THIS:` sections and not SOW `## Non-goals`. Reopening requires the
evidence named in each file, plus a ruling.

Template for a new record:

- **Rejected capability**
- **Why** it is outside Zero Employee's authority or current economics
- **Existing seam / workaround**
- **Evidence that would justify reopening**
- **Prior requests / rulings**
