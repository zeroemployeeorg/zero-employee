# Execution contracts (A1–A6)

kind: minor

New optional CLI/schema surface: product glossary (`CONTEXT.md`),
`ExecutorCapabilities`, JSON `ExecutionReceipt` (`zeo execution validate|import`),
optional Sandcastle evidence adapter (fixtures only), `zeo dispatch` ownership
library, `docs/non-goals/`, and this release-fragment gate.

Not a breaking artifact change: existing corpora lint as before when no
`executions/**/*.execution.json` files are present.
